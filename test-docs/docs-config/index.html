Setting Up the Public Documentation Repository

Step 1: Create the Public Repo

  1. Go to https://github.com/new
  2. Create a new repository:
  3. Name: job-application-assistant-docs
  4. Description: "Documentation for Job Application Assistant"
  5. Public (important!)
  6. DO NOT initialize with README, .gitignore, or license
  7. Click "Create repository"

Step 2: Generate Deploy Keys

Run these commands in your terminal:

cd /home/dave/Desktop/job_application_assitant/docs-config

# Generate the deploy key pair (no passphrase - just press Enter twice)
ssh-keygen -t ed25519 -f job-docs-deploy-key -C "davidbzyk@gmail.com"

Step 3: Add Keys to GitHub

Add Public Key to Public Repo:

  1. Go to your new job-application-assistant-docs repo
  2. Settings → Deploy keys → Add deploy key
  3. Title: "Docs Deploy Key"
  4. Key: Copy contents of job-docs-deploy-key.pub
  5. Check "Allow write access"
  6. Add key

Add Private Key to Private Repo:

  1. Go to your private job_application_assistant repo
  2. Settings → Secrets and variables → Actions
  3. New repository secret
  4. Name: ACTIONS_DEPLOY_KEY
  5. Value: Copy contents of job-docs-deploy-key (no .pub)
  6. Add secret

Step 4: Set Up GitHub Actions

Create the workflow directory and copy the deploy file:

mkdir -p /home/dave/Desktop/job_application_assitant/.github/workflows
cp /home/dave/Desktop/job_application_assitant/docs-config/deploy-docs.yml /home/dave/Desktop/job_application_assitant/.github/workflows/

Step 5: Update the Workflow

Edit .github/workflows/deploy-docs.yml and update line 44 to use your GitHub username:

git clone git@github.com:YOUR_GITHUB_USERNAME/job-application-assistant-docs.git docs-public

Step 6: Enable GitHub Pages on Public Repo

  1. Go to the public job-application-assistant-docs repo
  2. Settings → Pages
  3. Source: Deploy from a branch
  4. Branch: gh-pages (will be created automatically)
  5. Folder: / (root)
  6. Save

Step 7: Commit and Push

cd /home/dave/Desktop/job_application_assitant
git add .github/workflows/deploy-docs.yml
git add docs-config/
git add README.md
git commit -m "feat: Add MkDocs documentation setup"
git push

That's it!

The GitHub Action will: 1. Trigger on push to main 2. Build the docs using MkDocs 3. Push to the public repo 4. GitHub Pages will serve them at: https://YOUR_USERNAME.github.io/job-application-assistant-docs/

Note on Updates

The workflow only triggers when these files change: - Any README.md file - Files in docs-config/ - Files in ai-docs/ - The workflow file itself

This prevents unnecessary builds.
