    Tools Directory

    This directory contains the core functionality that powers all agents in the LinkedIn Applier system. These tools are imported and used by various agents to perform database operations, Google API interactions, memory management, and utility functions.

    🛠️ Core Modules

    database.py

    Central database operations module handling all SQLite interactions.

    Key Functions: - Job Management - add_job() - Add new scraped job - update_job_status() - Update job status in pipeline - get_job_details() - Get complete job information - get_jobs_by_status() - Retrieve jobs by status

    • Application Tracking
    • reserve_job_for_application() - Atomic job reservation
    • update_job_status_applied() - Mark job as applied
    • release_job_reservation() - Release failed reservation

    • get_applied_urls_by_role_type() - Duplicate prevention

    • Resource Management

    • get_jobs_needing_resources() - Jobs without folders/resumes
    • update_job_folder_id() - Store Google Drive folder ID

    • get_job_folder_id() - Quick folder lookup

    • Content Generation

    • get_jobs_ready_for_content() - Jobs with resources ready
    • reject_job_with_reason() - Mark job as not qualified
    • get_jobs_by_content_level() - Filter by content needs

    Database Schema: 

    CREATE TABLE jobs (
    id INTEGER PRIMARY KEY,
    company_name TEXT NOT NULL,
    job_title TEXT NOT NULL,
    job_url TEXT UNIQUE NOT NULL,
    job_description TEXT,
    application_status TEXT DEFAULT 
    role_type TEXT, 
    drive_folder_id TEXT,
    resume_link TEXT,
    cover_letter_link TEXT,
    applied_date TEXT,
    rejection_reason TEXT,
    -- timestamps and metadata
)

    google_api_tools.py

    Comprehensive Google API integration for Drive, Docs, and Gmail.

    Key Functions: - Authentication - get_drive_service() - Drive API client - get_docs_service() - Docs API client - get_gmail_service() - Gmail API client

    • Folder Operations
    • create_company_folder_resource_manager() - Create job folders
    • find_company_folder() - Search for existing folders

    • list_files_in_folder() - List folder contents

    • Document Operations

    • copy_google_drive_file() - Copy resume to job folder
    • create_cover_letter_only() - Create cover letter doc
    • convert_google_doc_to_pdf() - PDF conversion

    • download_file_from_drive() - Download for submission

    • Gmail Integration

    • search_gmail_for_verification_code() - Get verification codes
    • extract_verification_code_from_html() - Parse email HTML

    memory.py

    ADK callback system for state management between agents.

    Key Callbacks: - populate_job_scraper_state() - Setup scraping parameters - scraping_results_callback() - Process scraping results - populate_resource_manager_state() - Setup resource creation - populate_content_generator_state() - Setup content generation - memorize() / recall_all() - State persistence

    State Flow Example: 

    # Orchestrator sets:
session.state['job_title'] = 'Python Developer'
session.state['content_level'] = 'cover_letter_only'

# Sub-agents access via callbacks:
def populate_job_scraper_state(ctx):
    job_title = ctx.session.state.get('job_title')
    # Use for scraping...

    debug_callbacks.py

    Logging callbacks for debugging agent interactions.

    Available Callbacks: - before_agent_callback() - Log before agent runs - after_agent_callback() - Log after agent completes - before_tool_callback() - Log before tool execution - after_tool_callback() - Log after tool completes - before_model_callback() - Log before LLM calls

    🚨 Important Notes

    1. Database Location: orchestrator_agent/tools/linkedin_jobs.db
    2. Credentials: Requires credentials.json or environment variables
    3. Rate Limiting: Google APIs have quotas - use batch operations
    4. Transaction Safety: All database operations are atomic
    5. Error Handling: Functions return structured dicts with status/error

    🔐 Security

    • Never commit credentials or tokens
    • Use environment variables for sensitive data
    • Database operations are parameterized (SQL injection safe)
    • Google OAuth tokens auto-refresh

    🔗 Dependencies

    • sqlite3 - Database operations
    • google-api-python-client - Google APIs
    • google-auth - OAuth authentication
    • PyPDF2 - PDF text extraction
    • beautifulsoup4 - HTML parsing (Gmail)
