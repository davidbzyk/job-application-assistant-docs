    Job Scraper Agent

    The Job Scraper Agent is responsible for finding and importing job opportunities from multiple job sites including LinkedIn, Indeed, Glassdoor, ZipRecruiter, and Google Jobs. It uses a combination of JobSpy integration and professional APIs to gather job listings while avoiding duplicates.

    🏗️ Architecture Overview

    Orchestrator → Job Scraper Agent → Independent Scrapers
                                        ├── LinkedIn (JobSpy)
                                        ├── Indeed (JobSpy/Apify)
                                        ├── Glassdoor (JobSpy)
                                        ├── ZipRecruiter (JobSpy)
                                        └── Google Jobs (SerpAPI)
                                              ↓
                                        Database (via callbacks)

    📁 Directory Structure

    job_scraper_agent/
├── __init__.py              # Exports job_scraper_agent
├── agent.py                 # Main LlmAgent definition
├── prompt.py                # Agent instructions
├── independent_scrapers.py  # Core scraping logic
├── site_agents/            # Per-site agent configurations (unused)
├── tools/                  # Professional API integrations
│   ├── apify_indeed_scraper.py      # Apify for Indeed
│   ├── serpapi_google_jobs_scraper.py # SerpAPI for Google
│   └── serpapi_usage_tracker.py      # API usage monitoring
└── tests/                  # Pytest tests with real data
    ├── test_independent_scrapers.py
    ├── test_jobspy_integration.py
    └── ... (various integration tests)

    🔄 Job Scraping Workflow

    1. Duplicate Prevention

    get_applied_urls_by_role_type() → Returns URLs already applied to

    2. Site Selection

    Agent supports single-site or multi-site scraping: - Single: source="linkedin" - Multi: source="all" → LinkedIn + Indeed + Glassdoor

    3. Scraping Process

    For each site: 1. Get site-specific scraper function 2. Execute with parameters (query, location, max_jobs) 3. Filter duplicates against applied URLs 4. Store new jobs in database with "Pending Review" status

    4. Error Handling

    • Continues on site failures
    • Reports per-site results
    • Aggregates total jobs found

    🛠️ Key Components

    Main Agent (agent.py)

    • LlmAgent with scraping tools
    • Uses callbacks for state management
    • Supports both sync and async operations

    Independent Scrapers (independent_scrapers.py)

    Central hub that routes to appropriate scraper: - JobSpy Integration: LinkedIn, Indeed, Glassdoor, ZipRecruiter - Professional APIs: SerpAPI (Google), Apify (Indeed backup) - User Agent Rotation: Prevents detection - Real-time Deduplication: Checks against applied URLs

    Prompt (prompt.py)

    Instructions for: - Parameter extraction from user queries - Multi-site coordination - Error recovery strategies - Result reporting format

    🔧 Configuration

    Default Parameters

    max_jobs = 5          # Per site limit
location = "United States"
is_remote = True      # Remote jobs preferred
easy_apply_only = False  # All jobs, not just easy apply
content_level = "cover_letter_only"  # Memorized in state

    API Keys Required

    # .env file
SERPAPI_API_KEY=xxx      # For Google Jobs
APIFY_API_TOKEN=xxx      # For Indeed backup

    JobSpy Configuration

    • User agent rotation enabled
    • Proxy support available
    • Country code: "USA"
    • Results type: "RECENT"

    📊 Database Integration

    Job Creation

    Each scraped job includes: - company_name, job_title, job_url - job_description (full text) - location, date_posted - application_status = "Pending Review" - role_type (detected from title) - source (which site it came from)

    Duplicate Prevention

    Before adding each job: 1. Check URL against applied jobs 2. Check company/title combination 3. Skip if already in database

    Callbacks

    • populate_job_scraper_state - Sets up scraping parameters
    • scraping_results_callback - Processes results and updates database

    🧪 Testing

    All tests use real data with minimal pulls:

    # Run all scraper tests
pytest orchestrator_agent/sub_agents/job_scraper_agent/tests/ -v

# Test specific scraper
pytest tests/test_linkedin_descriptions.py -v

    Test Coverage

    • test_independent_scrapers.py - Core scraping logic
    • test_jobspy_integration.py - JobSpy functionality
    • test_jobspy_user_agent_rotator.py - Anti-detection
    • test_serpapi_google.py - Google Jobs API
    • test_apify_indeed.py - Indeed API backup

    🚨 Important Notes

    1. Rate Limiting: Built-in delays between sites
    2. User Agent Rotation: Prevents blocking
    3. Error Recovery: Continues if one site fails
    4. Real Descriptions: Fetches full job descriptions
    5. Location Handling: Normalizes remote/location data

    🔍 Debugging

    Enable debug logging: 

    import logging
logging.getLogger('jobspy').setLevel(logging.DEBUG)

    Common issues: - No results: Check VPN/proxy settings - Blocked: Rotate user agents more frequently - API limits: Check SerpAPI/Apify quotas - Duplicates: Verify applied_urls list is current

    🌐 Supported Sites

    Primary (JobSpy)

    • LinkedIn: Best for professional roles
    • Indeed: Largest job database
    • Glassdoor: Good for company reviews
    • ZipRecruiter: Strong for US jobs

    Professional APIs

    • Google Jobs: Via SerpAPI for comprehensive results
    • Indeed API: Via Apify as backup option

    Site-Specific Features

    • LinkedIn: Easy Apply filter available
    • Indeed: Salary data when available
    • Glassdoor: Company ratings included
    • Google: Aggregates from multiple sources

    🔗 Dependencies

    • JobSpy - Core scraping library
    • SerpAPI - Google Jobs access
    • Apify - Indeed API access
    • BeautifulSoup - HTML parsing
    • httpx - Async HTTP requests
