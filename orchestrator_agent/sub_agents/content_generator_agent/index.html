    Content Generator Agent

    The Content Generator Agent is responsible for analyzing job fit and generating tailored cover letters for qualified positions. It processes jobs that have been prepared by the Resource Manager (with folders and resumes already in place) and determines which jobs David should apply to based on his experience and the job requirements.

    🏗️ Architecture Overview

    The Content Generator has two modes of operation:

    1. Regular Mode (≤25 jobs):
   Orchestrator → Content Generator Agent → Direct Processing

2. Batch Mode (>25 jobs):
   Orchestrator → Batch Content Generator → Content Worker (per batch)
                     ├── Batch 1 (25 jobs) → 60s cooldown
                     ├── Batch 2 (25 jobs) → 60s cooldown
                     └── Batch N (remaining jobs)

    📁 Directory Structure

    content_generator_agent/
├── __init__.py               # Exports content_generator_agent
├── agent.py                  # Regular agent for ≤25 jobs
├── batch_content_generator.py # Custom BaseAgent for >25 jobs
├── prompt.py                 # All prompts (regular and batch)
├── readme.md                 # This file
└── tests/
    ├── conftest.py           # Pytest fixtures (real components)
    ├── test_content_generator.py       # Tests for regular agent
    ├── test_batch_content_generator.py # Tests for batch agent
    └── run_tests.py          # Test runner

    🔄 Content Generation Workflow

    Prerequisites

    • Jobs must be in "Pending Review" status
    • Each job must have:
    • drive_folder_id (created by Resource Manager)
    • resume_link (copied by Resource Manager)
    • role_type (engineer or product)

    Processing Steps

    1. Retrieve Jobs 

      get_jobs_ready_for_content() → Returns jobs with folders & resumes

    2. For Each Job:

    3. Get full job details including role_type
    4. Select appropriate resume (engineer vs product)
    5. Analyze job fit based on David's experience
    6. If qualified: Generate cover letter

    7. If not qualified: Reject with specific reason

    8. Document Creation (if qualified)

    9. Generate personalized cover letter content
    10. Create Google Doc in existing folder
    11. Convert to PDF

    12. Update database with document links

    13. Status Updates 

      Pending Review → Ready To Apply (qualified)
Pending Review → Not a Fit (rejected)

    🎯 Job Fit Analysis

    Auto-Accept Roles

    • AI Engineering: AI Engineer, AI Application Developer, Training Data Engineer
    • Product Management: Technical Product Manager, AI Product Manager
    • Senior Engineering: Senior Python Developer, Tech Lead
    • Full-Stack: Python backend + React/Angular frontend
    • Data Engineering: Snowflake, BigQuery, data pipelines
    • Fintech: Any finance/trading technology roles

    Auto-Reject Criteria

    • Non-US locations
    • Non-English job descriptions
    • Requires 20+ years experience
    • Completely different fields (doctor, lawyer)
    • Entry-level only positions
    • Pure ML Engineer roles (PyTorch/TensorFlow from scratch)

    Remote Work Policy

    Accept as remote-friendly: - Remote-first, Fully remote, 100% remote - Hybrid, Distributed team - Occasional offsites are OK

    Reject only if: - On-site only - In-office required daily/weekly - Specific city with no remote option

    🛠️ Key Components

    Regular Content Generator (agent.py)

    • LlmAgent for processing ≤25 jobs
    • Direct processing without batching
    • Uses centralized prompt from prompt.py
    • Tools:
    • Database: get_jobs_ready_for_content, update_job_status, reject_job_with_reason
    • Google Drive: create_cover_letter_only, convert_google_doc_to_pdf
    • Memory: memorize, recall_all

    Batch Content Generator (batch_content_generator.py)

    • Custom BaseAgent for >25 jobs
    • Processes in batches of 25 with 60s cooldowns
    • Fresh LLM context per batch
    • Automatic rate limit handling
    • Progress reporting per batch

    Prompts (prompt.py)

    • CONTENT_GENERATOR_AGENT_PROMPT - Regular processing
    • BATCH_CONTENT_PROMPT - Batch processing
    • Both include:
    • Job fit criteria
    • Cover letter template
    • First-person voice instructions

    🔧 Configuration

    Batch Processing Settings

    batch_size = 25          # Jobs per batch
cooldown = 60           # Seconds between batches
extended_cooldown = 90  # On rate limit errors

    Model Configuration

    model = GEMINI_2_5_FLASH  # For both regular and batch

    📊 Database Integration

    Required Job Fields

    • id, company_name, job_title, job_description
    • drive_folder_id - Google Drive folder ID
    • resume_link - Resume document URL
    • role_type - 'engineer' or 'product'

    Functions Used

    • get_jobs_ready_for_content() - Get jobs needing content
    • get_job_details(job_id) - Full job information
    • get_job_folder_id(job_id) - Quick folder lookup
    • update_job_status() - Mark as Ready/Not a Fit
    • reject_job_with_reason() - Reject with explanation

    🧪 Testing

    Run all tests: 

    cd tests
./run_tests.py

    Test Philosophy

    • Real components, no mocks
    • Uses actual database connections
    • Minimal data pulls for speed
    • Tests both regular and batch processing

    🚨 Important Notes

    1. Resource Manager Dependency: Jobs must have folders/resumes before content generation
    2. Role Type Critical: Each job's role_type determines which resume is used
    3. Rate Limiting: Batch mode prevents Google API quotas
    4. First Person Voice: Cover letters must use "I/my/me", never third person
    5. Skip vs Reject: Missing resume = skip (not reject) for later processing

    🔍 Debugging

    Check logs: 

    import logging
logging.basicConfig(level=logging.DEBUG)

    Common issues: - No jobs found: Check if Resource Manager has processed jobs - Missing folder_id: Job hasn't been through Resource Manager - Rate limits: Use batch mode for >25 jobs - Wrong resume: Verify job's role_type is set correctly

    🔗 Dependencies

    • Google ADK - Agent framework
    • Google Drive API - Document creation
    • SQLite - Job database
    • Gemini 2.5 Flash - LLM for content generation
