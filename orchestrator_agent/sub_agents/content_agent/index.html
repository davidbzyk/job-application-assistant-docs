    Content Agent

    The content agent owns the end-to-end content pipeline inside the ADK job application assistant. It replaces the legacy "single worker" flow with four dedicated workflows that move a job from raw resume review all the way to ready-to-apply Google Drive artifacts.

    Ready For Content
    v similarity_loop     (checks fit, writes score + reason)
Ready For Resume
    v resume_loop         (builds custom resume text)
Ready For Cover Letter
    v cover_letter_loop   (writes cover letter markdown)
Ready For Docs
    v docs_loop           (creates Docs + PDFs + links)
Ready To Apply

    All four loops execute under the Orchestrator via the ADK web component. Each loop is an LlmAgent armed with ADK tools and wrapped in a LoopAgent, so the system continually pulls new jobs while eligible rows remain in SQLite.

    Stage Details

    1. similarity_loop (similarity_scorer)

    • Entry condition: jobs.application_status IN ('Ready For Content','Checking Similarity') with non-empty resume_text.
    • Step 1 tool: asses_profile_determine_similarity_score() selects a job and sets status to Checking Similarity to lock the row.
    • Step 2 tool: process_similarity_score(job_id, similarity_score, similarity_reason) stores the score + tagged reason and promotes rows to Ready For Resume when score >= 6, otherwise Not a Fit.
    • Prompt: SIMILARITY_SCORER_PROMPT2 enforces the rubric, policy gates, and JSON-only tool calls.
    • Loop guard: similarity_loop_checker stops once no additional rows match; otherwise the loop immediately claims the next job.

    2. resume_loop (resume_creator)

    • Entry condition: application_status IN ('Ready For Resume','Crafting Custom Resume') with similarity >= 6 and a resume seed.
    • Step 1 tool: asses_similarity_determine_resume_content() bundles job context and marks the row Crafting Custom Resume.
    • Step 2 tool: process_custom_resume(job_id, custom_resume) persists the bespoke resume, advances status to Ready For Cover Letter, and caches text for doc generation.
    • Prompt: RESUME_CREATOR_PROMPT locks in ATS formatting, quantified bullets, and pagination rules.
    • Loop guard: resume_loop_checker mirrors the similarity checker to keep iterating while work remains.

    3. cover_letter_loop (cover_letter_creator)

    • Entry condition: application_status IN ('Ready For Cover Letter','Crafting Cover Letter') with a saved custom resume.
    • Step 1 tool: assess_profile_determine_cover_letter() retrieves the job bundle and sets status Crafting Cover Letter.
    • Step 2 tool: process_cover_letter(job_id, cover_letter_text) saves the letter, advances to Ready For Docs, and records the markdown for the Docs pipeline.
    • Prompt: COVER_LETTER_PROMPT3 enforces the two-step workflow and fixed letter template (letterhead + three paragraphs + closing).
    • Loop guard: cover_loop_checker continues until there are no more rows ready for cover letter creation.

    4. docs_loop (docs_pipeline)

    • Entry condition: application_status = 'Ready For Docs' with both custom_resume and cover_letter_text populated.
    • Step 1 tool: prepare_documents_for_generation() atomically claims one job and updates status to Creating Docs.
    • Step 2 tool: finalize_documents(job_id, custom_resume, cover_letter_text, drive_folder_id)
    • Injects content into Google Docs with tight margins, bold/links, and bullet styling.
    • Exports both Docs to PDFs and stores Drive links in the database (custom_resume_link, cover_letter_link, custom_resume_link_pdf, cover_letter_link_pdf).
    • Runs the optional fit-to-pages pass controlled by RESUME_MAX_PAGES.
    • Sets application status to Ready To Apply.
    • Deterministic agent: DocsPipelineAgent extends BaseAgent to wrap both tool calls, emit ADK events, and capture errors.
    • Convenience tool: run_docs_now() exists for "one-click" completion when invoked from other ADK contexts.
    • Loop guard: docs_loop_checker mirrors the other checkers to churn through the backlog.

    Tools Used

    • asses_profile_determine_similarity_score - claims the next content-ready job and locks it for similarity scoring.
    • process_similarity_score - writes score and rubric reason, promoting strong matches to resume generation.
    • asses_similarity_determine_resume_content - bundles resume-ready job context and flips status to crafting mode.
    • process_custom_resume - saves the bespoke resume text and advances the job to cover letter generation.
    • assess_profile_determine_cover_letter - retrieves the job plus custom resume for cover letter drafting and locks the row.
    • process_cover_letter - saves the formatted cover letter and moves the job to docs preparation.
    • prepare_documents_for_generation - claims Ready For Docs jobs and returns resume, cover letter, and Drive folder details.
    • finalize_documents - builds Google Docs, exports PDFs, stores Drive links, and marks the job Ready To Apply.
    • run_docs_now - convenience wrapper to execute the docs pipeline without starting the full loop.
    • check_similarity_loop_condition, check_resume_loop_condition, check_cover_loop_condition, check_docs_loop_condition - loop guard tools that decide when each agent should keep pulling work.

    Orchestration & Control

    • LoopAgents: Each loop is instantiated with max_iterations=5. Loop checkers manage state so the Orchestrator can invoke the loops repeatedly without busy-waiting.
    • Orchestrator-driven execution: The main orchestrator invokes each LoopAgent.
    • Callbacks: general_before_model_callback and similarity_before_model_callback enforce user/model turn ordering, intercept_and_correct_tool_call strips stray text, and simple_after_tool_callback logs every tool response.

    Logging & Diagnostics

    • utils/logging_config.py centralizes logging into timestamped EST log files under utils/logs/ and mirrors key events to stdout. Set CONTENT_CONSOLE_LEVEL=DEBUG to increase console verbosity while keeping full debug output on disk.
    • Structured [DOCS], [AFTER_MODEL_LOG], and [BEFORE_AGENT] entries in agent.py make it easy to trace progress across the four loops.

    Testing & Evaluations

    • The tests/ package covers loops, tool layers, prompts, and end-to-end flows. See tests/README.md for the full breakdown.
    • tests/evals/content_generator_eval_001.evalset.json (and siblings) feed ADK's AgentEvaluator to validate the two-step workflows without hitting live models. Tests monkeypatch the model for determinism but the eval harness is wired for the same evaluation model used in production ADK runs.
    • tests/golden_responses/ stores prompt regression fixtures that mirror live trajectories.
    • Run everything with pytest -v orchestrator_agent/sub_agents/content_agent/tests. Targeted runs (e.g., eval harness or DB tooling) can be executed with the individual file paths outlined in tests/README.md.
