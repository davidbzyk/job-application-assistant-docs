Job Application Assistant Chrome Extension

🚀 Quick Start

Loading the Extension in Chrome

  1. Open Chrome and navigate to chrome://extensions/
  2. Enable "Developer mode" (toggle in top right)
  3. Click "Load unpacked"
  4. Select the chrome-extension/dist folder
  5. The extension icon (JA) should appear in your toolbar!

Testing the Extension

  1. Visit a job listing on:
  2. LinkedIn (e.g., linkedin.com/jobs/view/...)
  3. Indeed (e.g., indeed.com/viewjob?...)
  4. Glassdoor

  5. ZipRecruiter

  6. Click the extension icon - you should see:

  7. "On Job Page" indicator
  8. Current job details extracted

  9. Save Job button

  10. Click "Save Job" to save it locally

🔧 Development

Setup

npm install

Development Mode (with hot reload)

npm run dev

Production Build

npm run build

📁 Project Structure

chrome-extension/
├── dist/               # Built extension (load this in Chrome)
├── src/
│   ├── popup/         # Extension popup UI
│   ├── content/       # Content scripts for job extraction
│   └── background/    # Service worker for API calls
├── manifest.json      # Extension configuration
└── webpack.config.js  # Build configuration
  • ✅ Chrome extension structure with Manifest V3
  • ✅ Job extraction for LinkedIn, Indeed, Glassdoor, ZipRecruiter
  • ✅ Popup UI with job saving functionality
  • ✅ Local storage for saved jobs
  • ✅ Multi-site support with site-specific parsers
